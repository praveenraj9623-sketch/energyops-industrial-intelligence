# EnergyOps — Industrial Energy Intelligence

EnergyOps provides reproducible intake, local PostgreSQL storage, historical SQL summaries, explicit hourly baseline eligibility, candidate investigation rules, verified local Apache Superset 3.0 dashboards, and a deployable snapshot-only Streamlit public presentation for the [UCI Steel Industry Energy Consumption dataset](https://archive.ics.uci.edu/dataset/851/steel%2Bindustry%2Benergy%2Bconsumption). The local CSV is ignored by Git. Source and database evidence are in `evidence/`.

Start with [START_HERE.md](START_HERE.md) for setup and commands. The [public presentation guide](docs/PUBLIC_PRESENTATION.md), [local Superset guide](docs/SUPERSET.md), [investigation rules](docs/INVESTIGATION_RULES.md), [baseline and eligibility guide](docs/BASELINE_AND_ELIGIBILITY.md), [SQL model guide](docs/SQL_MODELS.md), [data contract](docs/DATA_CONTRACT.md), [quality audit](docs/DATA_QUALITY.md), [PostgreSQL guide](docs/POSTGRESQL.md), [ingestion guide](docs/INGESTION.md), [source attribution](docs/SOURCE_ATTRIBUTION.md), [limitations](docs/LIMITATIONS.md), and [architecture](docs/ARCHITECTURE.md) describe the source and project scope.

Phase 5 found 1,343 distinct candidate hours among 7,762 eligible hours: 1,263 consumption-positive hours, 105 lagging-power-factor review hours and 25 meeting both rules. Two-hour persistence produced 238 consumption and 5 power-factor candidate incidents. Phase 6 serves these verified views through three local Superset dashboards: [operations](http://127.0.0.1:8090/superset/dashboard/1/), [investigation](http://127.0.0.1:8090/superset/dashboard/2/), and [power-factor review](http://127.0.0.1:8090/superset/dashboard/3/). The public Streamlit presentation is prepared for [praveen-energyops.streamlit.app](https://praveen-energyops.streamlit.app/); deployment of that URL has not been verified here. Run it locally with `python -m streamlit run app.py`. Apache Superset is the primary local SQL dashboard layer; Streamlit reads only the committed snapshot. These are historical engineering review candidates, not confirmed waste, faults, or equipment incidents. Local scheduled EnergyOps alert delivery remains planned.
